# AI Career Assistant

AI-powered career assistance platform for students and job seekers.

## Features

- Resume Review Agent
- ATS Score Analyzer
- JD Match Analysis
- Interview Prep Generator
- Career Recommendation Engine
- Cover Letter Generator
- Skill Gap Analyzer
- Weekly Progress Report

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- n8n Workflow Automation
- Groq LLM API
- Google Sheets Logging

## Environment Variables

Create `.env.local`:

NEXT_PUBLIC_CAREER_API_URL=your-webhook-url

## Run Locally

npm install
npm run dev

## Deployment

Frontend: Vercel  
Backend: n8n Cloud
